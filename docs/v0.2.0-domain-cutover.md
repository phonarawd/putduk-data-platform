# v0.2.0 Domain Cutover Gate

기준일: 2026-09-21 KST  
상태: **PENDING / BLOCKED UNTIL DOMAIN MAPPING IS EXPLICIT**

이 문서는 v0.2.0 최종 출시에서 사용할 도메인 cutover SSOT다. 현재 저장소와 운영 배포에 남아 있는 `hiptk.app` / `putduk.kr` 값은 **현 상태 inventory**일 뿐, v0.2.0 최종 도메인으로 승인된 값이 아니다.

`docs/stage12-release-freeze.md`의 기존 `hiptk.app 변경 금지` 서술은 v0.2.0 최종 release 판정에 사용하지 않는다. 새 member/ops mapping이 명시되기 전에는 DNS/Auth/CORS/canonical/final release를 확정하지 않는다.

## 1. 현재 release-critical inventory

현재 branch 기준으로 도메인 값이 직접 release 동작에 영향을 주는 파일은 다음과 같다.

| 영역 | 파일 | 현재 역할 |
| --- | --- | --- |
| SEO / runtime | `dist/index.html` | canonical, OG URL, JSON-LD, `memberOrigin`, `opsOrigin` |
| Admin runtime | `dist/admin/index.html` | `memberOrigin`, `opsOrigin` |
| Member/Ops 분리 | `dist/assets/origin-split.js` | admin redirect 및 member/ops host 판별 |
| Cloudflare edge routing | `functions/_middleware.js` | ops redirect, official member host, recovery path |
| Search engine | `dist/robots.txt` | sitemap absolute URL |
| Search engine | `dist/sitemap.xml` | public member absolute URLs |
| Cloudflare smoke | `tooling/cloudflare/verify-deployment.mjs` | 명시된 member/ops production origin 검증 |
| Supabase Edge CORS | `supabase/functions/_shared/http.ts` | `PUTDUK_ALLOWED_ORIGINS` secret 기반 origin 허용 |

추가로 Supabase Auth의 Site URL / Redirect URL allow-list는 저장소 파일이 아니라 Production Auth 설정이므로 cutover 시 별도로 확인해야 한다.

## 2. 새 mapping 입력 계약

최종 mapping이 결정되면 최소한 아래 두 origin이 명시되어야 한다.

- `MEMBER_URL` 또는 `MEMBER_DOMAIN`: 회원 production origin
- `OPS_URL` 또는 `OPS_DOMAIN`: 운영자 production origin

두 값은 서로 달라야 하며 production에서는 HTTPS origin이어야 한다. path/query/hash를 origin 값에 포함하지 않는다.

예시는 의도적으로 넣지 않는다. 새 mapping을 추측하거나 과거 도메인을 기본값으로 재사용하지 않는다.

## 3. 자동 domain gate

```bash
pnpm domain:audit
```

현재 release-critical 파일의 absolute origin inventory만 출력한다. mapping 미입력은 `PENDING`으로 표시한다.

```bash
MEMBER_URL=<member-origin> OPS_URL=<ops-origin> pnpm release:domain
```

최종 release gate다. 다음 항목이 모두 target origin과 일치해야 PASS한다.

- member canonical
- member OG URL
- member JSON-LD Organization/WebSite
- member runtime `memberOrigin` / `opsOrigin`
- admin runtime `memberOrigin` / `opsOrigin`
- robots sitemap URL
- sitemap 전체 `<loc>`
- `origin-split.js` member/ops host
- Cloudflare middleware member/ops host

명시적 target이 없으면 release gate는 fail-closed한다.

## 4. Production cutover 순서

도메인 값이 확정된 뒤에도 아래 순서를 지킨다.

1. **Mapping 고정**
   - member origin
   - ops origin
   - 기존 origin을 redirect-only로 남길지 여부
   - recovery origin 정책
2. **DNS/custom-domain/TLS 준비**
   - 새 host가 실제 production Pages project로 연결될 준비가 되었는지 확인
   - 이 단계만으로 기존 runtime canonical을 바꾸지 않는다.
3. **Supabase Auth 선행 허용**
   - Site URL / Redirect URL allow-list에 새 member/ops 흐름을 반영
   - 기존 로그인 세션/이메일 redirect가 끊기지 않도록 전환 구간을 둔다.
4. **Supabase Edge CORS 선행 허용**
   - `PUTDUK_ALLOWED_ORIGINS`에 새 member/ops origin을 포함
   - 전환 중에는 필요하면 기존 origin과 새 origin을 함께 허용하고, cutover 안정화 후 old origin을 제거한다.
5. **필수 Edge Function 배포 및 smoke**
   - `member-task-detail`
   - `admin-work-asset`
   - 저장소 deploy/verify contract에 포함된 나머지 Edge Function과 JWT 정책도 재확인
   - unauthenticated 요청은 보호 함수에서 401/403이어야 한다.
6. **정적/runtime origin 변경**
   - 위 inventory 파일을 새 mapping으로 일괄 변경
   - `pnpm release:domain` PASS 확인
7. **Cloudflare static deploy**
   - member/ops 새 origin에서 shell/runtime fingerprint 확인
   - old member URL이 남는 경우 redirect 정책 확인
8. **Live auth smoke**
   - dedicated trial/member 계정
   - dedicated admin 계정
   - 로그인 → member/admin 경계 → logout/cache cleanup
   - 실제 PII 값은 로그/assertion에 남기지 않는다.
9. **최종 release 판정**
   - domain gate PASS
   - Edge inventory/JWT PASS
   - DB integrity read-only PASS
   - live E2E가 실행된 경우 결과 기록
   - Draft 해제/merge/tag는 별도 최종 지시에서만 수행

## 5. Rollback 순서

새 static deploy 이후 문제가 확인되면 DB 금액/업무 데이터를 건드리지 않는다.

1. 정적 앱을 마지막 known-good commit으로 복원하거나 forward-fix
2. member/ops routing을 마지막 정상 mapping으로 복원
3. Auth redirect allow-list는 rollback 세션이 안정될 때까지 old/new를 모두 허용할 수 있다.
4. Edge CORS도 rollback 안정화 전까지 old/new origin을 동시에 허용할 수 있다.
5. 누락 Edge Function을 삭제해서 rollback하지 않는다. 호환되는 마지막 정상 버전을 재배포한다.
6. DB migration은 자동 down migration하지 않고 forward-fix 원칙을 유지한다.

## 6. 현재 판정

현재 v0.2.0 domain gate는 **PENDING**이다.

- 새 member origin: 미확정
- 새 ops origin: 미확정
- Supabase Auth mapping: 미확정
- `PUTDUK_ALLOWED_ORIGINS` 최종 값: 미확정
- `member-task-detail` Production 배포: 미완료
