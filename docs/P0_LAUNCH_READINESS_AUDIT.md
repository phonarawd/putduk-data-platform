# P0 출시 전 미완성 버튼·임시 문구 전수조사

기준일: 2026-09-20
기준 브랜치: `main`
최상위 기준: `docs/PUTDUK_MASTER_FINAL_ARCHITECTURE.md`

## 분류 기준

- **출시 필수·정상 동작**: 실제 서버 또는 현재 운영 흐름에 연결된 기능. 유지.
- **의도적 안전 잠금**: 서버 계약/권한/데이터가 없을 때 잔액·상태를 임의 변경하지 않도록 막는 안전장치. 유지.
- **운영 상태 문구**: 실제 데이터가 아직 없거나 비동기 조회 중임을 뜻하는 문구. 개발 중처럼 보이지 않게 표현만 정리.
- **레거시·개발 잔존**: 현재 렌더 경로에서 사용되지 않거나 버튼 없이 핸들러만 남은 코드. 사용자에게 노출되지 않으면 즉시 기능 변경하지 않고 후속 리팩터링 대상으로 기록.
- **제거 대상**: 눌러도 실제 기능 없이 안내 토스트만 띄우는 가짜 버튼. 출시 화면에서 숨김.

## 이번 패치 범위

1. 회원 근무 내역의 서버 미구현 `내역 내려받기` 버튼 제거.
2. `회원번호 준비 중` → `회원번호 확인 중`.
3. `코드 준비 중` → `추천 코드 확인 중`.
4. 체험 노드 없음 상태 `첫 업무 준비 중` → `현재 가능한 첫 업무 없음`.
5. 운영 설정 화면에 `지원금 캠페인 저장 계약 ... 아직 없습니다`가 표시된 경우 `설정 저장` 버튼 비활성화 및 `서버 연결 필요` 표시.
6. SPA 재렌더 후에도 위 정책을 다시 적용.

## 변경하지 않는 영역

- 회원 홈 FOMO/봇 로직 및 표시 수치
- `bot_enabled`, `crowd_min`, `crowd_max`, `burn_per_minute`, `crew_pulse`
- 지갑/원장/출금/입금 RPC 및 Supabase 데이터
- 실제 업무 제출/검수 로직
- 서버 미지원 시 잔액·상태를 변경하지 않는 보호 경로

## 후속 소스 정리 대상

동작에는 영향을 주지 않지만 번들 내부에는 아래 레거시가 남아 있다.

- 사용되지 않는 `renderAuthModal()` 구형 렌더 함수
- 노출 버튼이 없는 `faq` action 핸들러

`export-history` 버튼·핸들러와 회원번호/추천코드/첫 업무 상태 문구는 `dist/assets/app.js` 소스에서 직접 정리했다. `launch-readiness-guard.js`는 방어용으로 유지한다.
